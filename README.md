# ♟️ Chess Vision Trainer

Интерактивный тренажер шахматного зрения. Две мини-игры для развития тактического и пространственного мышления.

[**🔗 Открыть тренажер**](https://aslyamov.github.io/Chess-Vision-Trainer/)

![Chess Vision UI](./preview.png)

## 🎮 Игры

### ⚔️ Шахи и взятия
Тренировка нахождения всех тактических ударов в позиции.

- **Режим «Без зевков»** — только ходы, не ведущие к потере фигуры (с анимацией опровержения)
- **Поочерёдный режим** — сначала белые шахи → белые взятия → чёрные (с авто-поворотом доски)
- **Умный таймер** — пауза во время анимации ошибки
- **Визуальная обратная связь** — стрелки найденных ходов, счётчики, звуки

### 🎯 Цвет поля
Тренировка пространственного зрения — определить цвет случайного поля по координатам.

- **Три вида доски**: Цветная / Нейтральная (одноцветная) / Без доски
- **Ориентация**: Белые снизу / Чёрные снизу / Случайная
- **Таймер** на ответ (0 — бесконечно)
- **Координаты** на доске (опционально)

## 📊 Статистика

- Общая серия активных дней (единая для обеих игр)
- История сессий, средняя точность, детализация ходов по категориям
- Лучшая серия в «Цвете поля»

## 🛠 Технологии

- **TypeScript** — строгая типизация, модульная ООП-архитектура
- **DaisyUI + TailwindCSS** — адаптивный UI, светлая/тёмная тема
- **Chess.js** — логика ходов и валидация
- **Chessground** — интерактивная доска от Lichess
- **PWA** — Service Worker, работает офлайн

## 📂 Структура

```
src/
  core/
    games/              # Модули игр (IGameModule)
      ChecksAndCapturesModule.ts
      FieldColorModule.ts
    ChessVisionTrainer.ts   # AppContext, регистрация модулей
    GameRegistry.ts         # Реестр игр
    GameSession.ts          # Сессия «Шахи и взятия»
    FieldColorGame.ts       # Логика «Цвет поля»
    StatsManager.ts         # Статистика сессий
    CommonStatsManager.ts   # Общая серия дней
    StatsScreen.ts          # Экран статистики
  ui/                   # UIManager, BoardRenderer, StatusManager
  utils/                # chess-utils, localization, error-handler
  types/                # TypeScript-типы
dist/                   # Скомпилированный JS (production)
```

## 🚀 Разработка

```bash
npm install
npm run build   # tsc + tailwind
npm run dev     # авто-сборка при изменениях
npm run serve   # локальный сервер
```
